# 📊 Sistema IoT e Machine Learning para Estoque Comercial

Repositório desenvolvido para o **Projeto Integrador** dos cursos de Engenharia de Computação e Ciência de Dados da **UNIVESP**. 

O projeto tem como objetivo auxiliar a empresa parceira (*On Sale Shop*) através do monitoramento ambiental em tempo real (temperatura e umidade) e da predição de consumo energético do estoque utilizando inteligência artificial.

## 🛠️ Tecnologias Utilizadas
* **IoT & Hardware:** Termo-higrômetros e disjuntor inteligente integrados via **API Tuya**.
* **Banco de Dados:** Scripts SQL relacionais para persistência de dados.
* **Ciência de Dados & Machine Learning:** Python (`Pandas`, `NumPy`, `Scikit-Learn`) utilizando o algoritmo **Random Forest Regressor**.

## 📂 Estrutura do Repositório
* `Banco_de_Dados_PI_4.sql` — Script de criação e estruturação do banco de dados.
* `Algoritmo_Previsao_PI_4.py` — Script em Python com o modelo preditivo e conexão preparada para o banco.
* `README.md` — Documentação oficial do projeto.
